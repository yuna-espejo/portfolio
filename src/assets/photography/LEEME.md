# Fotos de la galería

Deja aquí tus fotos (.jpg, .jpeg, .png, .webp, .avif). Aparecen solas en
`/es/photography`, `/en/photography` y `/ca/photography`, sin tocar código.

- Se ordenan por nombre de archivo. Para controlar el orden, numéralas:
  `01-atardecer.jpg`, `02-calle.jpg`...
- El nombre (sin número ni extensión) se usa como texto alternativo y como pie
  de foto: `02-calle-de-noche.jpg` → "calle de noche".
- Se optimizan solas al compilar: puedes subir las originales.
- Para quitar una foto, bórrala de esta carpeta.
